FORMA DOM Manager v2.6

- Удалено поле «Материалы по индивидуальному расчету» из каталожной конфигурации.
- Удалено отображаемое поле «Базовая цена» из карточки каталога. Базовая цена продолжает учитываться внутри расчета автоматически.
- Убраны все приписки стоимости из выпадающих списков опций: например «С ящиком для белья (+18 000 ₽)» теперь отображается как «С ящиком для белья».
- Доплаты при этом продолжают автоматически прибавляться к итоговой цене позиции.
- Ручная кнопка «Редактировать цену» сохранена.
