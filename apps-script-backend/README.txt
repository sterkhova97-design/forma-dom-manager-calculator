ОБЩАЯ ИСТОРИЯ КП — ОДНОРАЗОВАЯ НАСТРОЙКА

1. В существующем проекте Google Apps Script замените WebApp.js на этот файл.
2. Нажмите «Начать развертывание» → «Новое развертывание» → тип «Веб-приложение».
3. Выполнять от имени: Я. Доступ: Все (Anyone).
4. Скопируйте URL, который заканчивается на /exec.
5. В GitHub-файле shared-history-config.js вставьте URL:
   window.FD_SHARED_HISTORY_API_URL = 'https://script.google.com/macros/s/.../exec';
6. Commit changes. После обновления GitHub Pages история станет общей для всех устройств.

Данные сохраняются в новом листе Google Таблицы «КП_HTML».
Редактирование старого КП обновляет ту же запись.
Фотографии, загруженные вручную, сохраняются в Google Drive в папку «фото для кп html».
