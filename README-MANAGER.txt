FORMA DOM — Manager HTML v1

Основа: дизайнерский калькулятор v3.1 (тот же каталог и формулы).
Добавлено: менеджер, клиент, срок изготовления, условия оплаты, НДС 22%, скидка, доставка, история КП, поиск по клиенту, редактирование сохранённых КП и PDF в стиле текущей Google-версии.

ВАЖНО: в этой сборке история хранится в localStorage браузера. Это полностью работает на одном компьютере/браузере. Для общей истории между несколькими менеджерами ManagerStorage нужно заменить на серверное API/БД.

Запуск: открыть index.html через локальный HTTP-сервер или загрузить папку на Cloudflare/GitFlic как обычную статическую HTML-версию.

UPDATE 14.08.2026 — PDF A4
- Кнопка «Создать КП (PDF)» теперь формирует и скачивает PDF напрямую, без системного окна печати.
- Формат каждой страницы: A4, альбомная ориентация (297×210 мм).
- Страницы КП рендерятся по фиксированной сетке 1200×848 px и помещаются в PDF как отдельные A4-страницы, поэтому Safari/Chrome больше не меняют масштаб и не разрывают блоки между страницами.
- Для генерации используются html2canvas 1.4.1 и jsPDF 2.5.1 через CDN.
