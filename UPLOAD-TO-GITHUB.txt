FORMA DOM — MANAGER CALCULATOR v1.4

ВАЖНО: файлы этого архива уже лежат в правильной структуре для GitHub Pages.
После распаковки загружайте СОДЕРЖИМОЕ архива прямо в корень репозитория.

В корне репозитория должны быть:
  index.html
  manager-v1.js
  manager-v1.css
  assets/
  .nojekyll
  и остальные служебные файлы

Не создавайте дополнительную папку forma-dom-manager-v1.x.

ШРИФТЫ:
В архиве файлы шрифтов не вложены. Положите ваши собственные файлы в:
  assets/fonts/Century_Gothic.ttf
  assets/fonts/Century_Gothic_Bold.ttf

- расчеты и каталог из дизайнерского калькулятора v3.1;

- клиент, проект, срок изготовления, условия оплаты;
- скидка, доставка/монтаж, НДС 22%;
- история КП в текущем браузере (localStorage) + поиск по клиенту;
- открытие/редактирование сохраненных КП;
- генерация и автоматическое скачивание PDF A4 landscape;
- макет КП на основе текущего фирменного шаблона Forma Dom.
