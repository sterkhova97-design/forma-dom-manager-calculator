FORMA DOM MANAGER — ЗАГРУЗКА НА GITHUB PAGES

1. Распакуйте архив.
2. Откройте папку и выделите ВСЁ её содержимое.
3. Загрузите файлы в корень репозитория forma-dom-manager-calculator.
   index.html должен лежать рядом с manager-v1.js и manager-v1.css,
   а не внутри дополнительной папки.
4. Commit changes -> main.
5. Settings -> Pages -> Deploy from a branch -> main -> /(root).

Страница:
https://sterkhova97-design.github.io/forma-dom-manager-calculator/

PDF:
Кнопка «Создать КП (PDF)» создаёт A4 Landscape напрямую, без окна печати Safari.
Если пользовательские файлы Century Gothic не загружены, PDF всё равно создастся
с системным fallback-шрифтом.
