Forma Dom Manager v1.8

Добавлено:
- Каталог Forma Dom из CSV сайта: 66 карточек, 481 ценовая вариация.
- Фото карточек подгружаются напрямую из URL Tilda CDN, указанных в CSV.
- Поиск и фильтр по категориям.
- Выбор конфигурации/вариации с сайта и ее актуальной цены из CSV.
- Ручное редактирование базовой цены позиции менеджером.
- Надбавка за индивидуальный размер: Нет / +15% / +20% / +25%.
- Автоматический расчет итоговой цены позиции.
- Редактирование каталожной позиции после добавления в КП.
- Каталожные позиции сохраняются в истории КП и попадают в PDF.
- В PDF отображаются фото, конфигурация, габариты и итоговая цена каталожной позиции.

Примечание по фото:
- В браузере фото грузятся с static.tildacdn.com по ссылкам из CSV.
- При добавлении позиции приложение пытается встроить фото как data:image для стабильного PDF.
- Если CDN запрещает CORS, интерфейс все равно показывает фото по URL; для 100% офлайн-PDF изображения лучше позже скопировать в assets/catalog-images.
