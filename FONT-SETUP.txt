CENTURY GOTHIC — ПОДКЛЮЧЕНИЕ

Калькулятор и PDF работают даже без файлов шрифта: если Century Gothic отсутствует,
используется системный fallback и PDF всё равно создаётся.

Чтобы на GitHub Pages использовался именно Century Gothic, загрузите СВОИ файлы в:

assets/fonts/Century_Gothic.ttf
assets/fonts/Century_Gothic_Bold.ttf

Названия должны совпадать точно, включая регистр.
После загрузки GitHub Pages автоматически начнёт использовать эти файлы.

Важно: файлы шрифта в этот архив не включены.
